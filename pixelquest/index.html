PixelQuest RPG

v1.0 // RELEASE_BUILD

React Canvas TypeScript Redux

// SYNOPSIS

PixelQuest RPG is a browser-based role-playing game that brings the golden age of 16-bit JRPGs to the modern web. Built with React and HTML5 Canvas, it features real-time turn-based combat, a procedurally generated fantasy world, and a chiptune soundtrack that'll transport you straight back to 1991.

// KEY_FEATURES

  • Procedurally generated dungeons with unique layouts each playthrough
  • Real-time turn-based combat system with animated sprite battles
  • Original chiptune soundtrack composed in Famitracker
  • Inventory system with 50+ unique items and equipment
  • Character progression with skill trees and stat allocation
  • Save/load system using localStorage with multiple save slots
  • Responsive design — plays on desktop and mobile browsers
