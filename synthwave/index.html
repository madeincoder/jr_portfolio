SynthWave FM

v2.0 // STABLE_RELEASE

Vue Web Audio CSS Anim Pinia

// SYNOPSIS

SynthWave FM is a retro-styled music streaming application that feels like a time capsule from the 1980s. With vinyl-spinning animations, a chiptune visualizer pulsing to the beat, and a curated library of synthwave, outrun, and retrowave tracks, it's the ultimate nostalgia trip for music lovers who grew up with neon lights and cassette tapes.

// KEY_FEATURES

  • Vinyl record UI with realistic spinning animation and album art display
  • Chiptune music visualizer with real-time frequency analysis
  • Curated playlists: Synthwave, Outrun, Vaporwave, Retrowave, Chillsynth
  • Dynamic audio equalizer with 8 preset modes
  • Cassette tape recording and mix-tape creation feature
  • Dark mode with multiple neon color themes to choose from
  • Keyboard shortcuts for power users (space, arrows, numbers)
