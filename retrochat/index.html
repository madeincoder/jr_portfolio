RetroChat AI

v1.5 // BETA_BUILD

Python LLM WebSocket FastAPI

// SYNOPSIS

RetroChat AI is an AI chatbot experience wrapped in a nostalgic terminal interface. Running on a custom fine-tuned language model, it delivers responses on a classic green phosphor display complete with CRT scanlines, cursor blinks, and authentic terminal sounds. It's like having a conversation with a mainframe from 1985 — if that mainframe had a modern AI brain.

// KEY_FEATURES

  • Custom fine-tuned LLM for retro-themed and tech conversations
  • Authentic terminal UI with green phosphor display and scanlines
  • Real-time streaming responses via WebSocket connection
  • Command palette with 20+ fun retro commands (/ping, /fortune, /hack)
  • Conversation history with searchable logs
  • Multiple AI "personalities" (Hacker, Professor, Pirate, Robot)
  • Export conversations as .txt or .log files
