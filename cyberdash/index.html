CyberDash

v1.0 // ARCADE_RELEASE

Three.js WebGL JavaScript WebAudio

// SYNOPSIS

CyberDash is a high-octane synthwave racing game that throws you onto an infinite neon-lit highway at breakneck speed. Built with Three.js and WebGL, it features procedurally generated tracks, pulse-pounding chiptune music, and a vibrant retro-futuristic aesthetic that'll make you feel like you're racing through a 1980s arcade dream.

// KEY_FEATURES

  • Infinite procedural highway with dynamic obstacles and traffic
  • Neon synthwave visual style with bloom, glow, and particle effects
  • Original chiptune soundtrack that syncs with gameplay intensity
  • Three difficulty modes: Cruise, Turbo, and Overdrive
  • Power-up system with shields, speed boosts, and score multipliers
  • Global leaderboard with daily and all-time rankings
  • Gamepad support for an authentic arcade feel
